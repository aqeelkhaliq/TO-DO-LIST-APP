# 📝 To-Do List App

A simple and interactive To-Do List web application built using **HTML, CSS, and JavaScript**. This project allows users to add, display, and remove daily tasks dynamically in the browser.

---

## 🚀 Features

- ➕ Add new tasks
- ❌ Remove specific tasks
- 🧠 Real-time UI updates
- 📋 Task management using JavaScript arrays
- 🎯 Clean and simple user interface
- 🖱️ Event handling using `addEventListener`

---

## 🛠️ Technologies Used

- HTML5  
- CSS3  
- JavaScript (Vanilla JS)
